# VisionFlow v0.1.0-beta.3

发布日期：2026-10-02。Windows x64 公开测试版，免安装。

## 数据标注

侧栏新增“数据标注”页面，用于把采集批次中的游戏截图制作成 YOLO 目标检测数据集。

- 支持选择图片目录、浏览图片和鼠标拖拽绘制矩形框。
- 支持删除选中框、清空当前图片全部框，并保存没有目标的图片为空标签负样本。
- 支持新增、重命名和删除类别。
- 重命名类别保留原数字编号，已有标签无需修改。
- 删除类别时可以删除该类别已有框，也可以合并到其他类别；后续类别编号会同步重排。
- 类别调整采用原子写入和失败回滚，避免 `classes.txt` 与图片标签只更新一部分。
- 支持导出 `images/train`、`images/val`、`labels/train`、`labels/val`、`classes.txt` 和 `data.yaml`。

## 视觉识别

- 图片等待、图片点击、窗口内图片等待和窗口内图片点击步骤新增可选“颜色相似度”。
- 在模板结构匹配通过后，继续检查命中区域颜色，减少半透明遮罩仍被识别为按钮的情况。
- 点击图片目标前会重新截图校验，颜色条件不满足时不会发送点击。

## 下载与验证

下载 `VisionFlow-v0.1.0-beta.3-windows-x64.exe`，直接运行，无需安装 Python。
使用同一 Release 中的 `SHA256SUMS.txt` 核对文件完整性：

```powershell
Get-FileHash .\VisionFlow-v0.1.0-beta.3-windows-x64.exe -Algorithm SHA256
```

- 冻结包自检通过：Qt 初始化、数据采集存储与去重、中文路径图片、图像匹配、颜色相似度校验和真实 RapidOCR 推理。

## 已知限制

- 本版没有自带游戏模型或模型训练功能；需要自行准备有权使用的数据和权重。
- 非 MuMu 程序的后台截图和输入兼容性取决于目标程序，最小化不保证可用。
- 采集和标注数据发布前请检查账号信息、聊天内容等隐私信息。
- 没有进行代码签名；Windows 可能提示程序来源未知。
- 源码回归及冻结包自检不等同于真实游戏、模拟器及干净 Windows 环境的全面验收。
