# VisionFlow v0.1.0-beta.2

发布日期：2026-09-29。Windows x64 公开测试版，免安装。

## 数据采集

侧栏新增“数据采集”，可选择具体游戏窗口，设置截图间隔和保存上限。

- 支持开始、暂停、继续、停止，以及暂停期间补拍。
- 全局补拍默认为 F10，可改为 F11、F12 或关闭。松开按键时触发，不拦截游戏键盘输入。
- 自动截图可跳过像素完全相同的图片；补拍始终保留且计入上限。
- 按游戏和时间批次保存完整 PNG、`frames.jsonl` 与 `session.json`。
- 采集仅获取画面，不发送鼠标或键盘操作；其他已启动的自动化任务不会自动停止。

## 视觉与运行器

- 窗口内 YOLO ONNX 检测、目标点击和条件判断，支持类别名称或编号及点击偏移。
- MuMu 成功关联 ADB 后使用同一实例截图和输入。
- 源码新增 `game_daily.py` 配置式日常入口，默认只预演，并提供多游戏配置示例。
- 修复停止后继续操作、ADB 子进程取消、程序关闭时的线程生命周期、YOLO 条件校验和模型导出路径同步。

## 下载与验证

下载 `VisionFlow-v0.1.0-beta.2-windows-x64.exe`，直接运行，无需安装 Python。
使用同一 Release 中的 `SHA256SUMS.txt` 核对文件完整性：

```powershell
Get-FileHash .\VisionFlow-v0.1.0-beta.2-windows-x64.exe -Algorithm SHA256
```

## 本版验证

- 93 项源码回归测试通过，依赖检查通过。
- 优化模式源码自检与独立冻结自检包均通过：Qt 初始化、采集存储与去重、补拍、中文路径图片、图像匹配和真实 RapidOCR 推理。
- 本机 Windows PrintWindow 采集测试窗口通过，取得完整 640 x 360 图像；采集页在 1120 x 720 和 920 x 620 尺寸下检查通过。
- 冻结自检包使用相同打包配置的专用入口，不是正式 EXE 的真实游戏流程验收。

## 已知限制

- 本版没有自带游戏模型、自动标注或模型训练功能；需要自行准备有权使用的数据和权重。
- 非 MuMu 程序的后台截图和输入兼容性取决于目标程序，最小化不保证可用。
- 采集默认保存完整画面；发布数据集前请检查账号信息、聊天内容等隐私信息。
- 同步 PrintWindow 与部分原生推理操作无法立即中断，关闭程序时会等待操作返回。
- 模型解码仅覆盖当前适配的 Ultralytics 检测输出，不支持所有导出协议。
- 日常运行器仍为实验性命令行功能，不应将其超时设置视为原生调用的硬截止时间。
- 没有进行代码签名；Windows 可能提示程序来源未知。
- 源码回归及本机 Windows 截图/冻结包自检不等同于真实游戏、模拟器及干净 Windows 环境的全面验收。
